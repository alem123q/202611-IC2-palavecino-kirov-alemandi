# Documentación

Esta carpeta contiene el informe del proyecto en PDF.

| Archivo | Contenido |
|---|---|
| `informe.pdf` | Informe del trabajo final (pendiente) |

El informe va a incluir:

- Requisitos de la consigna y cómo los cumple el sistema
- Decisiones de diseño (arquitectura, sensores, regla de iluminación, ahorro de energía)
- Diagrama de conexiones con los pines del ESP32-C3
- Protocolo MQTT y comandos
- Pruebas realizadas y resultados
